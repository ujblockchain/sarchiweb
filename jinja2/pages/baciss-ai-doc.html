Service Delivery Reporter (Community Voice)

Citizens report local service problems (water, electricity, roads, sanitation, waste) by text, voice note, and an optional photo, in English, isiZulu, isiXhosa, Afrikaans, or Sesotho. AI agents triage the report, check the web for known outages, route it to a department, flag duplicates, and draft a reply. Citizens sign in to submit and follow their own reports. An admin reviews the report, then the reply. Nothing is ever sent externally without approval.

How a report moves through the system

Privacy Filter (Local) Triage (Lang/Cat/Urg) Routing (Municipality/Dept) Context Check (Web Outages) Duplicate Check Save to SQLite Human Review Drafter (Policy Reply) Draft Approval Citizen Conversation

Step-by-Step Setup

1. Install uv (v0.13.7) Run once
Windows (PowerShell): 
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/0.13.7/install.ps1 | iex"
macOS / Linux: 
curl -LsSf https://astral.sh/uv/0.13.7/install.sh | sh
2. Install Python 3.12 & Synced Libraries From project root 
uv python install 3.12
uv sync --locked
Verify: uv run python --version and uv pip list | grep -E "^(langgraph|langchain|fastapi|pydantic|chromadb|fastmcp|streamlit) "
3. Configure Environment Keys (.env) 
cp .env.example .env
Variable Used For Where to Get
GEMINI_API_KEY Triage, drafting, voice transcription aistudio.google.com
GROQ_API_KEY Routing, web check console.groq.com/keys
TAVILY_API_KEY Live web outage search app.tavily.com
JWT_SECRET Signing auth tokens Generate with: openssl rand -hex 32
Optional: Uncomment LangSmith variables (LANGSMITH_API_KEY, LANGSMITH_TRACING, LANGSMITH_PROJECT) for cloud trace visualization.
4. Seed Default Test Accounts 
uv run python -m community_voice.auth.seed
5. Install Ollama Privacy Model 
ollama pull llama3.2:3b
6. Setup Frontend (Next.js) 
cd frontend && npm ci && cp .env.example .env.local && cd ..
7. Offline Test Suite Verification 
uv run pytest

Local Privacy Filter (Ollama)

Pre-Cloud PII Scrubbing

Before any report reaches external cloud models, a local Ollama model removes personal data (names, street addresses, phone numbers, ID numbers, emails). Recognized place names (e.g. "Umlazi") are preserved for routing.

  • Fallback: If Ollama is offline, reports are stopped unless the citizen ticks consent.
  • CPU Weak Mode: Set PRIVACY_FILTER=false in .env to disable local LLM scrubbing (regex numbers/emails still strip).
  • Evaluation: Run uv run python -m evals.run_privacy_evals to benchmark redaction accuracy.
Check Ollama status: curl http://localhost:11434
